# Simple Note App

A basic notes app that help users write, update and delete notes.

## Features
* **Create Notes:** Create new notes.
* **Delete Notes:** Remove notes if you no longer need them.
* **Responsive Design:** Works smoothly on both mobile and desktop screens.

## Built With
* HTML5 / CSS3 / JavaScript / React

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Install the dependencies using npm install.
4. Start the development server using npm run dev.
5. Vite will display a local URL in the terminal, usually http://localhost:5173.
